# Kitae's website, now Kamae's

Kitae is now called Kamae, and its website moved to [kamae.fromkoyomi.org](https://kamae.fromkoyomi.org). It's in the app's repository now, in the `docs/` folder of [koyomi-apps/kamae](https://github.com/koyomi-apps/kamae).

This repository only keeps the old address, kitae.fromkoyomi.org, working: GitHub Pages serves a page here that sends visitors on to the new one, from any path, as `404.html` is the same page as `index.html`.
